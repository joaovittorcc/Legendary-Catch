# Referências de cutscenes das Lendárias

Uma pasta por criatura Lendária do catálogo atual. Cada pasta inclui o prompt individual de geração e a prancha disponível do modelo atual. Ao receber os vídeos do João, coloque a referência correspondente como `generated-cutscene.mp4`; depois a animação no jogo pode ser adaptada por código.

Total catalogado: 18 criaturas. As Místicas C93/C94 ficam fora deste conjunto.
